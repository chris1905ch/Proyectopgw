# Vínculo Laboral

Portal de búsqueda de empleo para El Salvador, hecho con Node.js, Express y PostgreSQL. Es el proyecto final de Desarrollo de Páginas Web Activas - B, de la Universidad Católica de El Salvador (ciclo II de 2026).

## Contenido del repositorio

Todo el código está en la carpeta `vinculo-laboral`. Ahí mismo se encuentra el README con los pasos para instalar PostgreSQL, crear la base de datos, cargar los datos de demostración y ejecutar la aplicación.

## Qué incluye

- Página de inicio, búsqueda de empleos con filtros y detalle de cada oferta.
- Registro de candidatos y de empresas, con verificación de las empresas por parte de administración.
- Publicación y administración de ofertas: editar, inactivar, cancelar y eliminar.
- Postulación de candidatos, y revisión de aplicantes con opción de aceptar o rechazar.
- Dashboards para candidatos y para empresas.
- Panel administrativo con usuarios, empresas, ofertas y estadísticas.
- Página de recursos y consejos de carrera.
- 50 pruebas automáticas, funcionales y de integración (`npm test`).
